## Setup
Signal Hound VSG60 (SCPI port 5124) → 30 dB pad → 1.5 m coax → BRD4265B. Level at the board = VSG − 30.5 dB.
Host: Windows, 4-deep USB hub chain, radioconda Python, SoapyIonos driver (branch `host/soapy-ionos`).

## Scripts (`scripts/`)
| File | Purpose |
|---|---|
| `vsg60.py` | minimal VSG60 SCPI client (freq/power/on/off/modulation/Arb), every set read back |
| `longprog.py` | 48 h characterisation loop: offset, passband/image at 3 rates, level staircase, USB counters, drift |
| `soapyio.py` | SoapySDR primitives (command, rate, capture, sensors, spectrum, noise density, CSV/log) |
| `wideband_soapy.py` | wideband map / edges / CW / FSK through SoapyIonos, `FGRST` recovery |
| `wideband.py` | same over direct serial (fallback) |
| `recheck.py` | re-check: noise with VSG off, ±6.25 kHz sidebands, FSK outliers ×3 |
| `fsk_lib.py` | 2-FSK PRBS9 Arb generator, discriminator demodulator, PRBS-aligned BER |
| `passband.py` | stand-alone passband sweep |
| `soak_full.py`, `soak200.py` | USB soaks: sequence check, per-second stats, ESP console log |
| `flood_exp.py`, `flood_exp2.py` | USB flood experiments (`UF`, `UP`, `UT`) |
| `con4.py` | send one ESP console command |

COM ports are hard-coded for the test PC (console `COM4`, data port found by VID 0x303A) — adjust locally.
The FSK Arb file is generated by `fsk_lib.py` (not committed).
